# AutoCheckZapret

Программа для автоматического подбора, скачивания и управления обходами DPI с использованием утилиты **Zapret** (форк **Flowseal** — [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)).  
Позволяет загружать разные версии, тестировать методы обхода и запускать Zapret как службу Windows.

---

## 📌 Назначение

- Скачивание выбранной версии **Zapret** из репозитория Flowseal.
- Автоматический подбор работающего метода обхода (перебор стратегий из `.bat`-файлов).
- Запуск Zapret как системной службы (через `sc.exe`) с найденными параметрами.
- Удобное управление из графического интерфейса.
- Сохранение настроек (выбранная версия, подобранный метод) между сеансами.

---

## 🖥️ Требования

- Windows 7/8/10/11 (x64)
- [.NET 10 Runtime](https://dotnet.microsoft.com/en-us/download) (или выше)
- Права администратора (для установки службы и драйвера WinDivert)
- Интернет-соединение (для скачивания Zapret)

---

## 🧭 Использование (пошагово)

### Шаг 1. Выбор версии
В выпадающем списке выберите нужную версию Zapret.  
Список загружается автоматически из репозитория Flowseal.

![Выбор версии](https://github.com/user-attachments/assets/e9c10fb3-bb4c-4338-bbad-61621e84b6f3)

---

### Шаг 2. Скачивание выбранной версии
Нажмите на кнопку **«Скачать»**.  
Программа загрузит архив, распакует его в папку `versions/{номер_версии}/` и подготовит файлы стратегий.

![Кнопка скачивания](https://github.com/user-attachments/assets/fc7e0cad-8f65-4475-994f-b967fefec80b)

---

### Шаг 3. Подбор обхода
После успешной загрузки нажмите кнопку **«Подобрать обход»** (она же «Запустить»).  
Программа последовательно протестирует все `.bat`-файлы в папке версии, пока не найдёт рабочий метод.  
Как только метод найден – Zapret автоматически запускается как служба и остаётся активным.

![Процесс подбора](https://github.com/user-attachments/assets/438c973b-e94c-4897-a124-b2857803e904)

---

### Шаг 4. Управление работой
- Если служба уже запущена, кнопка изменится на **«Остановить»** – нажмите её, чтобы остановить Zapret и удалить службу.
- Если хотите сменить версию – сначала остановите текущую, затем выберите другую версию и повторите шаги 1–3.

## 🗂️ Структура хранения данных

В папке с программой автоматически создаются:

- `versions/` — каталог со скачанными версиями Zapret (каждая в своей подпапке).
- `appdata.json` — файл с сохранёнными настройками (последняя выбранная версия, список скачанных версий и их методы).

Каждая скачанная версия содержит:
- все файлы из релиза `zapret-discord-youtube`
- файлы стратегий (`.bat`) в корне папки версии
- папки `bin/` (с `winws.exe` и `WinDivert.dll`) и `lists/`

---


## ⚙️ Принцип работы подбора

1. Программа скачивает выбранную версию `zapret-discord-youtube`.
2. Парсит все `.bat`-файлы в корне версии.
3. Для каждого файла извлекает аргументы запуска `winws.exe`.
4. Устанавливает временную службу и запускает `winws.exe` с этими аргументами.
5. Проверяет подключение к ключевым URL (связанным с youtube и discord).
6. Если все URL возвращают ответ — метод считается рабочим; служба остаётся активной.
